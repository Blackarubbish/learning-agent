# BM25 算法原理

## 一句话概括

BM25 是一种基于词频的概率检索算法，回答的核心问题是：**一个词在一篇文档中出现得越多，同时在其他文档中出现得越少，这个词对这篇文档的区分度就越高。**

## 核心公式

```
Score(D, Q) = Σ IDF(qi) × (f(qi,D) × (k1+1)) / (f(qi,D) + k1 × (1-b+b×|D|/avgdl))
```

可以把公式拆成两大部分：**IDF 项** 和 **TF 项**。

---

## 第一部分：IDF — 词的区分能力

```
IDF(qi) = log((N - n(qi) + 0.5) / (n(qi) + 0.5))
```

- `N`：全部文档数
- `n(qi)`：包含词 qi 的文档数

**含义**：一个词在越少的文档中出现，IDF 值越大，说明这个词越"独特"。

| 词 | 出现文档数 | IDF 值 | 含义 |
|---|---|---|---|
| "的" | 100/100 | 极低 | 停用词，无区分能力 |
| "深度学习" | 5/100 | 高 | 专业术语，区分能力强 |
| "FAISS" | 1/100 | 极高 | 罕见词，区分能力极强 |

**直观理解**：如果用户搜 "FAISS 向量检索"，"FAISS" 的权重远大于"向量"，因为 "FAISS" 更稀少、更有区分度。

---

## 第二部分：TF — 词频饱和与长度归一化

```
(f(qi,D) × (k1+1)) / (f(qi,D) + k1 × (1-b+b×|D|/avgdl))
```

### 2.1 词频饱和（k1 参数）

TF 项不是简单的词频计数，而是对词频做了**饱和处理**：

- 词出现 1 次贡献大
- 出现 2 次贡献增加但增幅变小
- 出现 10 次和 20 次差距已经很小

**`k1` 控制饱和速度**（通常 1.2）：
- k1 越大 → 饱和越慢 → 词频越高分数越高
- k1 越小 → 饱和越快 → 低词频就能获得较高分数

**为什么需要饱和？** 防止"堆词"作弊。一篇文档重复 100 次"深度学习"不应该比重复 3 次的高出几十倍。

### 2.2 长度归一化（b 参数）

分母中的 `k1 × (1-b+b×|D|/avgdl)` 做了文档长度归一化：

- `|D|`：当前文档长度（词数）
- `avgdl`：平均文档长度
- `b`：长度归一化参数（通常 0.75）

**长度归一化的效果**：

| 文档长度 | |D|/avgdl | 归一化效果 |
|---|---|---|
| 短文档（|D| < avgdl）| < 1 | 分母变小 → TF 分数提升（补偿短文档词频天然低） |
| 平均长度 | = 1 | 无额外影响 |
| 长文档（|D| > avgdl）| > 1 | 分母变大 → TF 分数降低（惩罚长文档词频天然高） |

**为什么需要长度归一化？** 长文档词多，同一个词出现概率更高。如果不做归一化，长文档天然占优势，但这不代表它更相关。

## 完整示例

假设有 3 篇文档，查询 "深度学习"：

```
文档A: "深度学习是机器学习的分支，深度学习使用神经网络"  (10个词，"深度学习"出现2次)
文档B: "深度学习"                                        (4个词，"深度学习"出现1次)
文档C: "今天天气不错"                                    (6个词，"深度学习"出现0次)
```

计算过程：
1. **IDF**："深度学习"只在 2/3 篇文档出现，IDF > 0
2. **TF 项**：
   - 文档A：词频 2，但文档偏长(10词 > avgdl≈6.7)，归一化后 TF 分数打折
   - 文档B：词频 1，但文档短(4词 < avgdl)，归一化后 TF 分数提升
3. **最终**：文档A 和 文档B 的分数可能接近，但文档B 因为短文档加成可能略高

## BM25 vs 向量检索

| 维度 | BM25 | 向量检索 |
|---|---|---|
| 匹配方式 | 精确词匹配 | 语义相似度 |
| 擅长场景 | 关键词查询、专有名词、产品ID | 同义词、语义关联、模糊描述 |
| 弱点 | "深度学习" 搜不到"深层神经网络" | "OpenAI GPT-4" 可能排在语义相关但关键词不匹配的文档后面 |
| 速度 | 快（倒排索引） | 取决于向量库规模 |
| 语言理解 | 无 | 有（通过 Embedding 模型） |

**结论**：两者互补，混合检索（BM25 + 向量 + RRF）是更优方案。
