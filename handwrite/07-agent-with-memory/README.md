# 07 — Agent 记忆与 RAG 集成

## 目标

给 06 的 Agent 基类接入短期记忆（对话历史管理）、长期记忆（向量存储）和 RAG 检索能力。

## 核心概念

三层记忆架构：
- **工作记忆**：当前会话的完整 messages 列表（06 已实现）
- **短期记忆**：滑动窗口，超出窗口的旧消息截断或摘要
- **长期记忆**：向量存储 + 语义检索，跨会话持久化用户偏好和关键决策

RAG 检索工具：用 FAISS/Milvus 向量搜索 + BM25 关键词检索 + RRF 融合。

## 你需要实现

1. **短期记忆管理器**：滑动窗口 + 摘要压缩
2. **长期记忆管理器**：FAISS 向量存储 + 语义检索
3. **RAG 工具**：向量检索 + BM25 关键词检索 + RRF 融合
4. **记忆注入**：每轮对话前从长期记忆中检索相关偏好，注入 system prompt

## 运行

```bash
uv run handwrite/07-agent-with-memory/starter.py
```
