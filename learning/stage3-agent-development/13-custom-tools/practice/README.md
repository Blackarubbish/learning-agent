# 13 - 自定义工具开发

## 目标

设计 AI 友好的工具接口，让同样的 LLM + 不同的工具 = 不同的 Agent。理解"70% 工作在工具端"的工程现实。

## 工具工程的四个核心原则

| 原则 | 说明 | 反例 |
|------|------|------|
| **信息抽象** | 总结 + 截断 + 引导，渐进式曝光 | 直接把 100 篇搜索结果全文丢给 LLM |
| **状态反馈** | 报告进度、成功/失败统计、剩余工作建议 | 只说"批量处理完成"不告诉几项成功几项失败 |
| **错误恢复接口** | 错误信息包含"原因 + 可用选项 + 正确示例" | 只返回 HTTP 500 |
| **结构化输出** | 用标题、编号、分段让 LLM 快速定位关键信息 | 返回无格式的 JSON dump |

## 三个练习工具

| 工具 | 核心训练点 |
|------|-----------|
| `smart_search` | 信息抽象：截断 10→3 条 + 摘要 + 引导探索 |
| `batch_process` | 状态反馈：3/5 成功 + 2 个失败详情 + 处理建议 |
| `api_fetch` | 错误恢复：每种错误码对应"发生了什么→为什么→你能做什么" |
