# 24 - 周度总结与性能压测

## 目标

用 locust 对优化前后的系统进行压测，产出完整的优化对比报告。

## 核心概念

- **locust** — Python 编写的负载测试工具，支持自定义测试场景
- **关键指标** — QPS、P50/P99 延迟、错误率、吞吐量
- **优化报告结构** — 基准数据 → 优化措施 → 效果量化 → 成本分析

## 实验设计

1. 用 locust 写一个测试脚本，模拟 N 个用户并发调用 ResearchAssistant
2. 分别压测"优化前"和"优化后"版本
3. 产出对比表格：

| 指标 | 优化前 | 优化后 | 提升 |
|------|--------|--------|------|
| QPS | | | |
| P50 延迟 | | | |
| P99 延迟 | | | |
| 缓存命中率 | | | |
| Token 消耗/查询 | | | |

## 总结维度

| 维度 | 回顾内容 |
|------|---------|
| Profiling | 瓶颈在哪？和预期一致吗？ |
| 缓存 | 命中率达到预期了吗？什么场景下缓存收益最大？ |
| 异步 | 并发加速比是多少？是否存在串行瓶颈？ |
| 批处理 | 批大小对吞吐量的影响曲线？最优值是多少？ |
| vLLM | 自部署 vs API 服务在成本和性能上的权衡？ |
